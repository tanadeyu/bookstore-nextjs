## 1. システム概要

### 1.1 目的
商品販売データを収集・分析し、売上状況を可視化するシステムを構築する。

### 1.2 対象ユーザー
- 小売業の店舗管理者
- 販売データの分析担当者
- 在庫管理担当者

### 1.3 想定運用環境
- Webブラウザ（最新版）
- Vercelホスティング

---

## 2. 機能一覧

| 機能ID | 機能名 | 概要 | 優先度 |
|--------|--------|------|--------|
| F01 | 商品管理 | 商品マスタの閲覧 | 高 |
| F02 | 顧客管理 | 顧客マスタの閲覧 | 高 |
| F03 | 販売管理 | 販売データの登録・閲覧（ヘッダーー明細構造） | 高 |
| F04 | 売上ランキング | 商品別売上順位の表示 | 中 |
| F05 | カテゴリ別集計 | カテゴリごとの売上集計 | 中 |
| F06 | 顧客別分析 | 顧客ごとの購入状況表示 | 低 |

### 3.2 テーブル定義

#### 3.2.1 customers（顧客マスタ）

| カラム名 | データ型 | 必須 | 説明 |
|---------|---------|------|------|
| id | INTEGER | ○ | 主キー（自動採番） |
| name | TEXT | ○ | 氏名 |
| email | TEXT | ○ | メールアドレス（ユニーク） |
| member_number | TEXT | - | 会員番号（ユニーク） |

#### 3.2.2 products（商品マスタ）

| カラム名 | データ型 | 必須 | 説明 |
|---------|---------|------|------|
| id | INTEGER | ○ | 主キー（自動採番） |
| name | TEXT | ○ | 商品名 |
| description | TEXT | - | 説明 |
| price | INTEGER | - | 価格 |
| stock | INTEGER | - | 在庫数（初期値0） |
| published_date | TEXT | - | 発行日 |

#### 3.2.3 categories（カテゴリマスタ）

| カラム名 | データ型 | 必須 | 説明 |
|---------|---------|------|------|
| id | INTEGER | ○ | 主キー（自動採番） |
| name | TEXT | ○ | カテゴリ名（ユニーク） |

#### 3.2.4 sale_headers（販売ヘッダー）

| カラム名 | データ型 | 必須 | 説明 |
|---------|---------|------|------|
| id | INTEGER | ○ | 主キー（自動採番） |
| customer_id | INTEGER | ○ | 顧客ID（外部キー） |
| sale_date | TEXT | ○ | 販売日 |

#### 3.2.5 sales（販売明細）

| カラム名 | データ型 | 必須 | 説明 |
|---------|---------|------|------|
| id | INTEGER | ○ | 主キー（自動採番） |
| header_id | INTEGER | ○ | ヘッダーID（外部キー） |
| product_id | INTEGER | ○ | 商品ID（外部キー） |
| quantity | INTEGER | ○ | 数量 |
| sale_price | INTEGER | ○ | 販売単価 |

#### 3.2.6 product_categories（商品-カテゴリ中間テーブル）

| カラム名 | データ型 | 必須 | 説明 |
|---------|---------|------|------|
| product_id | INTEGER | ○ | 商品ID（外部キー） |
| category_id | INTEGER | ○ | カテゴリID（外部キー） |

## 4. 機能詳細

### 4.1 商品管理（F01）
商品情報の一覧表示を行う。

### 4.2 顧客管理（F02）
顧客情報の一覧表示を行う。

### 4.3 販売管理（F03）
販売データの登録と閲覧を行う。**ヘッダーー明細構造**を採用し、1回の購入で複数商品を登録可能。

### 4.4 売上ランキング（F04）
商品別の売上順位を表示する。

### 4.5 カテゴリ別集計（F05）
カテゴリごとの売上を集計表示する。

### 4.6 顧客別分析（F06）
顧客ごとの購入状況を表示する。
