# 開発方法 - BookStore Next.js

**更新日**: 2026-04-27

## 環境

- Node.js 20以上（LTS推奨）, npm
- VS Code + ESLint + Tailwind CSS IntelliSense

## セットアップ

```bash
git clone <repo>
cd bookstore-nextjs
cd nextjs
npm install
npm run dev
```

**環境再現性:** `package-lock.json` で全員が同じバージョンを使用。`node_modules/` は `.gitignore` 除外。

### Step 1: Next.js プロジェクト作成

```bash
cd bookstore-nextjs
mkdir nextjs
cd nextjs
npx create-next-app@latest . --typescript --tailwind --eslint --app --yes
```

**オプション:**
- `--typescript`: TypeScript使用
- `--tailwind`: Tailwind CSS使用
- `--eslint`: ESLint使用
- `--app`: App Router使用
- `--yes`: 対話モードをスキップ（デフォルト設定を適用）

**生成される構造:**
```
nextjs/
├── app/              # App Routerページ
├── public/           # 静的ファイル
├── package.json      # 依存関係
├── tsconfig.json     # TypeScript設定
└── tailwind.config.ts # Tailwind設定
```

### Step 2: 依存関係追加

**Drizzle ORM & SQLite:**
```bash
cd nextjs
npm install drizzle-orm better-sqlite3
npm install -D drizzle-kit
```

**shadcn/ui 初期化:**
```bash
cd nextjs
npx shadcn@latest init --yes --defaults
```

**生成される構造:**
- `components/ui/` - shadcn/ui コンポーネント
- `lib/utils.ts` - ユーティリティ関数
- `components.json` - shadcn/ui 設定

### Step 3: データベーススキーマ定義

**作成ファイル:**
- `drizzle/schema.ts` - DB スキーマ定義
- `drizzle/config.ts` - Drizzle 設定
- `lib/db.ts` - DB クライアント

### Step 4: マイグレーション + データ初期化

```bash
cd nextjs
npx drizzle-kit generate --config=drizzle/config.ts
npx drizzle-kit push --config=drizzle/config.ts
npx tsx drizzle/seed.ts
```

**生成されるファイル:**
- `bookstore.db` - SQLite データベース
- `drizzle/migrations/` - マイグレーションファイル
- `drizzle/seed.ts` - 初期データスクリプト

### Step 5: 基本レイアウト (Root Layout + Navigation)

**作成ファイル:**
- `components/navigation.tsx` - ナビゲーションコンポーネント
- `app/layout.tsx` - Root Layout（ナビゲーション追加）
- `app/products/page.tsx` - 商品一覧
- `app/customers/page.tsx` - 顧客一覧
- `app/sales/page.tsx` - 販売一覧

### Step 6: ダッシュボード (ランキング、集計)

**作成ファイル:**
- `app/page.tsx` - ダッシュボードページ（Server Component）

**機能:**
- 売上ランキング（上位10件）
- カテゴリ別集計
- 顧客別分析（上位10件）

### Step 7: 商品管理ページ

**作成ファイル:**
- `app/products/page.tsx` - 商品一覧ページ（Server Component）

**機能:**
- 全商品を一覧表示
- ID、商品名、説明、価格、在庫数を表示

### Step 8: 顧客管理ページ

**作成ファイル:**
- `app/customers/page.tsx` - 顧客一覧ページ（Server Component）

**機能:**
- 全顧客を一覧表示
- ID、氏名、メールアドレス、会員番号を表示

### Step 9: 販売管理ページ (一覧 + 詳細)

**作成ファイル:**
- `app/sales/page.tsx` - 販売一覧ページ
- `app/sales/[id]/page.tsx` - 販売詳細ページ

**機能:**
- 販売一覧（ヘッダー情報表示）
- 販売詳細（ヘッダー + 明細表示、合計金額計算）
- 動的ルーティング（`/sales/[id]`）を使用

## データベース

### Drizzle ORM とは

TypeScript/JavaScript 用の軽量な ORM ライブラリ。

**特徴:**
- TypeScript 親和（型安全なクエリ）
- 軽量・高速（Prisma より軽量）
- SQL-like なクエリビルダー
- SQLite と相性が良い

**使用例:**
```typescript
// 全件取得
const users = await db.select().from(users);

// 条件指定
const user = await db.select().from(users).where(eq(users.id, 1));

// 挿入
await db.insert(users).values({ name: "John", email: "john@example.com" });
```

### コマンド

```bash
npx drizzle-kit generate  # マイグレーション生成
npx drizzle-kit push       # スキーマをDBに反映
npx drizzle-kit studio     # DB GUI
```

**データベース:** SQLite (`bookstore.db`)
