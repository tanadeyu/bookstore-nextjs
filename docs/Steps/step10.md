# Step 10: 販売登録フォーム (Server Actions)

**実施日**: 2026-04-27
**ステータス**: ✅ 完了

## 目的

販売登録フォームを作成し、Server Actions を使用して販売データを登録する。

## 実装ファイル

### 1. Server Actions

**ファイル:** `nextjs/app/sales/actions.ts`

- `createSale()` - 販売登録（在庫管理付き）
- `getCustomersForSelect()` - 顧客一覧取得
- `getProductsForSelect()` - 商品一覧取得
- `deleteSale()` - 販売削除

### 2. 販売登録ページ

**ファイル:** `nextjs/app/sales/new/page.tsx`

- 固定3行フォーム（Reference版準拠）
- 顧客選択、販売日入力
- 商品3つ、数量入力
- 商品選択時に価格表示

### 3. 削除機能

**ファイル:** `nextjs/app/sales/DeleteButton.tsx`

- 販売一覧からの削除（詳細ページにはなし）

## 機能

### 販売登録フォーム
- 固定3行（商品1、商品2、商品3）
- 顧客選択（ドロップダウン）
- 販売日入力
- 商品選択時に価格表示（例: `TypeScript入門 (¥2800)`）
- 数量入力のみ（単価は商品マスタから自動取得）

### 在庫管理
- 在庫チェック（在庫不足時はエラー）
- 販売登録時に在庫を減算
- `stock = stock - quantity` で減算

### データフロー
1. ユーザーがフォーム入力（3行固定）
2. Server Action で処理
3. 商品情報取得（価格、在庫）
4. 在庫チェック
5. ヘッダー登録 → 在庫減算 → 明細登録
6. キャッシュ再検証 → 一覧へリダイレクト

## 制約事項

- better-sqlite3 のトランザクション制約により、トランザクション不使用
- 明細は固定3行（動的追加なし）
- 単価は商品マスタから自動取得
